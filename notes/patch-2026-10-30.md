> 곡괭이 비교 사진과 동작은 같은 카메라·시간으로 만든 실제 게임 모델의 검수 렌더입니다. 잔디 비교 사진은 이번 배포 코드로 같은 장면을 이전 표면과 새 표면으로 그린 실제 게임 화면입니다.

## 한눈에 보기

**포근한 곡괭이**를 가방에서 꺼내 쓸 수 있는 도구 아이템으로 추가했습니다. HOME과 TT가 몸 가까이 쥐고, 준비한 뒤 앞으로 내려찍도록 다듬었습니다. 빠르게 다시 공격하거나 도구를 내려놓을 때 생기던 어색함도 줄였습니다. 들판과 섬의 **잔디는 풀잎이 보이는 새 질감**으로 바뀌었습니다.

손잡이가 옆으로 길게 뻗어 보이던 각도를 줄였습니다. 손잡이를 손에서 따로 옮기지 않고 **팔·손·도구를 함께 돌려**, 엄지와 손바닥 사이의 접점을 유지했습니다.

블록 검수 화면에서 다듬어 온 새 잔디 질감을 게임에도 적용했습니다. 돌 · 나무 · 책장 · 물음표 블록처럼 무늬가 있는 블록은 지금의 그림을 그대로 씁니다.

## 새로 추가

- **도구 아이템: 포근한 곡괭이** — `E → 도구`에서 꺼내 핫바에 넣고 선택할 수 있어요. 새 게임과 기존 저장 모두 기본 곡괭이 1개를 제공하며, 원래 핫바 칸은 유지해요.
- **곡괭이 공격 모드** — 곡괭이 슬롯을 선택하면 손에 장착되고 HUD에 공격 모드가 표시돼요. 다른 아이템을 고르거나 `Q`로 빈손을 선택하면 해제돼요.
- **클릭과 연속 공격** — 왼쪽 클릭으로 한 번 내려찍고, 길게 누르면 반복해요. 버튼을 놓으면 진행 중인 동작을 끝내요. 장비나 자세를 바꾸면 공격을 취소해요.
- **네 가지 옵션** — 곡괭이를 든 상태에서 `R`로 기본·가벼운 손잡이·석재 집중·정밀한 날을 바꿀 수 있어요.

### 사용 방법

| 조작 | 동작 |
| --- | --- |
| E → 도구 | 포근한 곡괭이를 찾아 원하는 핫바 칸에 넣기 |
| 1–9 또는 마우스 휠 | 곡괭이를 넣은 칸 선택 |
| 왼쪽 클릭 | 한 번 공격 |
| 왼쪽 버튼 길게 누르기 | 연속 공격·채굴 |
| R | 곡괭이 옵션 변경 |
| Q 또는 다른 아이템 칸 | 빈손으로 바꾸거나 다른 아이템 선택 |

`H`는 기존 조작법 메뉴로 유지합니다.

## 개선

### 손과 도구의 동작

- **몸 가까이 드는 자세** — 손잡이의 바깥 기울기를 줄였어요. HOME과 TT에 같은 기준으로 적용했어요.
- **손과 손잡이의 접점** — 대기·걷기·달리기·방향 전환 중에도 엄지와 손바닥 사이에 손잡이가 붙어 있도록 맞췄어요.
- **앞으로 내려찍기** — 팔만 작게 움직이지 않고, 준비한 곡괭이 머리가 몸 앞으로 내려오도록 했어요. 상체도 작게 따라 움직여 무게가 실리는 느낌을 더했어요.
- **이어지는 준비와 복귀** — 동작 중간마다 멈칫하던 구간을 줄이고, 연속 공격이 자연스럽게 이어지도록 다듬었어요.
- **작은 이동 흔들림** — 걷고 달릴 때 손과 도구가 함께 작게 흔들려요. 방향을 바꾸거나 멈춘 뒤에는 흔들림이 가라앉아요.
- **장착 해제 후 복귀** — 도구를 내려놓을 때 팔과 상체가 즉시 원위치로 튀지 않고 짧게 이어서 돌아와요.

![같은 실제 게임 리그로 본 최종 곡괭이 공격: 준비하고 앞으로 내려찍은 뒤 복귀하는 측면 동작](/note/assets/20261030-pickaxe-strike.webp)

측면에서는 화면 오른쪽이 캐릭터 앞입니다. 곡괭이 날이 실제로 앞으로 내려오는 구간에 블록 타격이 들어갑니다.

![왼쪽부터 곡괭이를 드는 준비, 몸 앞으로 내려찍기, 손을 되돌리는 복귀 자세](/note/assets/20261030-pickaxe-stages.webp)

### 블록 표면

- **새 잔디 · 눈 · 보석 질감** — 잔디는 풀잎이 보이는 연두색, 눈과 보석 블록도 새 질감으로 바뀌었어요. 게임 조명에서 어둡게 보이지 않도록 밝기를 맞췄어요.
- **가까운 곳과 먼 곳이 같은 질감** — 멀리 있는 땅도 가까운 땅과 같은 새 질감으로 이어져요.
- **가벼운 질감 파일** — 질감 파일 용량을 약 85% 줄여 처음 불러오는 시간이 늘지 않도록 했어요.

### 아이템과 채굴

- **장착과 저장 연결** — 가방의 보유 수량과 선택한 핫바 칸으로 장착을 결정해요. 저장을 불러오면 도구와 핫바도 함께 복원돼요.
- **동작과 판정의 타이밍 일치** — 기본 주기 0.72초의 58% 지점에서 블록에 채굴량을 적용해요. 허공에서는 공격 동작만 재생해요.
- **첫 블록에만 타격** — 조준한 첫 고체 블록이 사거리와 정면 범위 안에 있을 때만 채굴해요. 기본 사거리는 2.4m예요.
- **가방 안내** — 도구 분류와 아이콘, 사거리·공격 주기·조작 안내를 추가했어요. 곡괭이를 든 동안에는 블록 설치 미리보기가 나타나지 않아요.
- **교실 장비 표시** — 친구가 선택한 곡괭이와 옵션·공격 동작을 중계하도록 연결했어요. 선생님의 건축 잠금은 유지되며 곡괭이로 친구에게 피해를 주지 않아요.

## 버그 수정

- **빠른 연속 클릭 누락** — 공격이 끝나기 전에 다시 누른 클릭이 빠지던 문제를 고쳤어요. 다음 공격 한 번까지 기억하며, 여러 번 눌러도 동작이 길게 쌓이지 않아요.
- **장착 해제 때 팔 튐** — 공격 중 도구를 내려놓거나 바로 다시 선택할 때 팔이 갑자기 돌아가던 문제를 줄였어요.
- **투명 도구의 잔상** — 도구가 나타나는 도중 윤곽선과 그림자만 먼저 생기거나, 투명한 도구가 뒤의 캐릭터를 가릴 수 있던 설정을 고쳤어요.
- **도구로 물을 떠버리던 문제** — 곡괭이나 블록을 들고 물을 클릭했을 때 물통 동작으로 들어가던 문제를 고쳤어요. 이제 물통을 선택했을 때만 물을 떠요.

## 알려진 문제

- 곡괭이 공격은 **지상에서 선 자세**를 기준으로 동작합니다. 점프·수영·앉기·눕기·기어가기와 자세 전환 중에는 공격을 중지합니다.
- 업데이트 직후 열려 있던 교실 화면은 새로고침해야 친구의 곡괭이가 보여요.

## 검증

- 전체 클라이언트 자동 검사 **467개 통과**. 이 중 손·어깨 연결, 아이템 장착과 실제 공격, 입력 누락을 확인하는 관련 검사 66개를 포함합니다.
- 타입 검사, 변경 파일 린트, 프로덕션 번들 빌드 통과.
- HOME·TT의 네 방향·네 옵션·정지/달리기 **64개 조합**에서 타격 날이 앞으로 내려가는지 확인했습니다. 30·60·144fps에서도 타격 프레임의 방향을 검사했습니다.
- 브라우저 두 개로 교실을 열어, 선생님이 가방에서 곡괭이를 꺼내 들면 학생 화면에 보이고 빈손으로 바꾸면 사라지는 것을 확인했습니다. 교실 자동 검사 45개 · 섬 자동 검사 7개 통과.
