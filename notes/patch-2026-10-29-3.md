> 사진은 실제 게임 코드에서 추출한 형상·재질의 모델 검수 렌더이며, 운영 사이트의 배포 전후 화면 캡처는 아닙니다.

## 한눈에 보기

블록의 조립감은 살리면서, 표면과 쌓임이 더 부드럽게 이어지도록 다듬었습니다. 흙·모래의 큰 자갈 무늬를 고운 질감으로 바꾸고, 돌과 통나무는 금이 생긴 자리에서 실제 조각이 떨어지도록 개선했습니다. 싱글 모드에서는 받침을 없앤 모래가 아래로 떨어져 다시 쌓입니다.

## 새로 추가

- **모래의 중력 낙하** — 싱글 모드에서 모래·붉은 모래의 받침을 없애면 아래로 떨어져 다시 쌓입니다. 바닥과 가구에 막히며, 플레이어·동물이 아래에 있으면 이동을 기다립니다. 흙과 사암은 낙하 대상이 아닙니다.
- **형태가 변하는 채굴 손상** — 금이 표면에만 보이던 표현에서, 균열 가장자리가 실제로 패이고 내부 단면이 드러나는 단계별 파손으로 바꿨습니다.
- **연결·지형 검수 화면** — 같은 재질과 다른 재질의 옆면 연결, 모서리, 잔디·흙의 수직 쌓임, 모래 낙하를 각각 확인할 수 있는 배치를 추가했습니다.

## 개선

### 블록 모양과 연결

- **작은 원형 돌기 2×2** — 평평한 블록 윗면에 작은 원형 돌기 4개를 배치했습니다. 이웃 블록의 돌기와도 일정한 간격으로 이어집니다.
- **외곽 정리** — 큰 사각 돌기의 가운데 구멍, 깊은 아랫면 홈, 진한 테두리를 제거했습니다. 바닥은 평평하게 정리하고 모서리는 부드럽게 다듬었습니다.
- **옆면 밀착** — 꽉 찬 블록은 재질이 달라도 옆면이 밀착하도록 개선했습니다. 나무와 돌처럼 재질이 다른 경우에는 표면 경계가 유지됩니다.
- **수직 쌓임** — 위아래 접합부에서 과하게 패이던 홈을 줄였습니다. 이웃 블록을 없애면 새로 드러난 바깥 모서리가 원래 마감으로 돌아옵니다.

![같은 나무끼리의 연결과 나무·돌 사이의 연결을 확인하는 모델 검수 사진](/note/assets/20261029-block-connections.webp)

같은 재질은 한 덩어리처럼 이어지고, 다른 재질은 표면 차이를 남기면서 옆면이 맞닿습니다. 경사·판처럼 빈 공간이 있는 형태까지 무조건 메우지는 않습니다.

### 흙·잔디·모래 질감

![최종 재질 확대: 왼쪽 잔디와 흙의 경계, 가운데 고운 흙 잔결, 오른쪽 미세한 무광 모래](/note/assets/20261029-ground-detail.webp)

- **묻힌 층의 초록 띠 제거** — 완전히 덮인 잔디·꽃잔디 층은 흙으로 표시하고, 드러난 맨 위에만 얇은 잔디층을 남깁니다. 저장된 블록 종류와 획득 아이템은 유지됩니다.
- **부드러운 흙 표면** — 흙과 잔디 옆면의 큰 원형 자갈 무늬와 강한 요철을 없앴습니다. 밝은 갈색의 잔결과 낮은 대비로 표면을 정리했습니다.
- **고운 모래 표면** — 덩어리나 구멍이 박힌 인상을 줄이고, 미세한 입자와 부드러운 색 변화가 보이는 무광 표면으로 다듬었습니다.
- **새 표면 유지** — 생성 에셋 검수 모드에서도 새 흙 표면을 유지하도록 맞췄습니다. 풀·눈·보석 등 다른 생성 재질은 유지합니다.

### 텍스처 변환과 적용

색상 그림만 교체하지 않고, 색·요철·빛 반응을 나눠 조정했습니다. 이번 최종 흙·모래 표면은 코드에서 만드는 재질 맵을 사용합니다.

| 구성 | 최종 적용 내용 |
| --- | --- |
| 색상 · 알베도 | 흙은 은은한 갈색 얼룩과 잔결, 모래는 밝은 색과 낮은 대비로 정리했습니다. 반복되는 원형 자갈 무늬를 없앴습니다. |
| 요철 · 노멀 | 큰 돌알갱이가 튀어나와 보이던 느낌을 줄였습니다. 흙은 눌린 잔결, 모래는 더 미세하고 약한 입자로 표현합니다. |
| 거칠기 · 러프니스 | 흙과 모래의 무광 성격을 유지합니다. 다른 재질의 금속 반사나 보석 광택까지 같은 질감으로 바꾸지는 않습니다. |
| 면과 층의 구분 | 잔디 윗면·옆면·아랫면을 나눠 적용하고, 덮인 잔디 층은 흙 표면으로 이어지게 했습니다. |
| 이전 텍스처 처리 | 새 흙·잔디 옆면 위에 이전 생성 텍스처가 다시 덮이는 경로를 정리했습니다. |

### 돌·통나무 파손

![위쪽은 돌, 아래쪽은 통나무의 정상 상태·균열 성장·조각 분리 단계](/note/assets/20261029-mining-stages.webp)

위쪽은 돌, 아래쪽은 통나무입니다. 왼쪽의 온전한 블록에서 가운데의 균열을 거쳐 오른쪽의 조각 분리로 진행합니다. 최종 블록 모양을 적용한 실제 파손 코드의 단계별 상태입니다.

- **반복감이 줄어든 균열** — 시작점, 작은 조각의 위치, 큰 덩어리의 비율을 바꿨습니다. 작은 조각이 모이는 부분과 큰 덩어리가 남는 부분을 섞었습니다.
- **안정적인 무작위성** — 같은 위치는 채굴 취소·재개 후에도 같은 형태로 갈라집니다. 파편의 분리 지연·회전·낙하 속도는 조금씩 달라지고, 손상 중이던 실제 조각은 그대로 이어집니다.
- **돌의 균열** — 맞은 지점에서 금이 뻗고, 균열 가장자리가 패인 뒤 모서리부터 떨어지도록 다듬었습니다. 몸체 전체가 동시에 부풀어 벌어지던 느낌을 줄였습니다.
- **나무의 결과 속살** — 결을 따라 금이 내려가고, 밝은 속살과 가는 나뭇조각이 먼저 드러납니다. 마지막에는 긴 조각이 순서대로 분리됩니다.
- **연속되는 파편** — 완전히 부서질 때 새 정육면체 파편으로 갑자기 바뀌지 않고, 손상 중이던 조각의 위치와 회전을 이어서 낙하합니다.
- **바닥 접촉** — 돌 조각이 바닥에 파묻히거나 서로 겹치는 부분을 보정했습니다. 긴 나무 조각은 바닥에 닿은 뒤 기둥처럼 서서 멈추지 않고 옆으로 넘어지도록 개선했습니다.
- **취소와 재개** — 채굴을 취소하면 원래 블록이 복원됩니다. 수동으로 부술 때도 현재 손상 상태에서 이어집니다.

## 버그 수정

- 절단면이 돌출부와 홈 사이의 빈 공간까지 잘못 연결해, 초반부터 크게 찢어진 것처럼 보이던 문제를 수정했습니다.
- 새 흙 질감 위에 이전 자갈 텍스처가 다시 덮어씌워지던 경로를 수정했습니다.
- 모래 낙하가 시작될 때 드러난 윗돌기가 사라지던 문제를 수정했습니다.
- 청크 경계와 월드 밖 좌표에서 낙하 셀을 숨기는 처리가 다른 셀의 표시에 영향을 줄 수 있던 문제를 수정했습니다.
- 월드가 스크롤된 뒤 모래 데이터는 남아 있는데 화면에서 빈칸처럼 보일 수 있던 문제를 수정했습니다.
- 높은 쌓임을 볼 때 검수 카메라가 모델을 제대로 담지 못하던 부분을 조정했습니다.
- 검수 화면에 **다른 균열 보기**를 추가했습니다. 일시정지 중 선택해도 계산 완료 후 새 패턴이 나타나며, 계산 중에는 원래 블록이 유지됩니다.
- 드물게 체적이 맞지 않는 절단 결과는 그대로 사용하지 않고 다른 시드로 다시 계산하도록 개선했습니다.
- 모래 낙하를 다시 확인할 수 있도록 **다시 배치하기**를 추가하고, 받침 제거 버튼의 상태를 정리했습니다.

## 알려진 문제

- 모래 낙하는 **싱글 플레이** 적용 범위입니다. 교실 모드의 서버 물리는 이번 패치에 포함되지 않습니다.
- 파손 연출의 정밀 조정과 모델 검수는 **돌·통나무 큐브**를 중심으로 진행했습니다. 다른 재질과 긴 블록·판·경사·모서리의 모든 파손 경우를 같은 수준으로 검수한 상태는 아닙니다.

## 검증

- 최종 클라이언트 자동 검사 **421개 통과**.
- 타입 검사, 변경 파일 린트, 프로덕션 빌드 통과.
- 재질·연결·쌓임·파손·모래 낙하의 모델 렌더와 동작 검사 수행.

돌 큐브·통나무 큐브·돌 경사의 32개 패턴, 총 **96개 조합**에서 원래 형상의 체적이 유지되는지 확인했습니다. 사진에는 블록·표면·균열의 전후 비교와 연결·파손·모래 낙하 과정을 담았습니다.
