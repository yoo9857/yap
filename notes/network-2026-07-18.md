안녕하세요, 크래프트얍입니다.

**2026년 7월 18일 오전**, 크래프트얍 온라인 서버가 가동을 시작했습니다. 이날부터
[craftyap.com](/)에서 보안 연결(HTTPS)로 게임에 접속할 수 있고, Daily Tower의
멀티플레이와 순위표가 서버로 운영됩니다.

## 서버로 운영되는 것

### Daily Tower 실시간 멀티플레이

- 같은 날의 타워에 도전하는 플레이어를 한 방에 **최대 8명**까지 모읍니다.
- 다른 플레이어의 움직임이 실시간으로 보이고, 움직이는 발판도 모두의 화면에서 같은 시각에 같은 자리에 있습니다.
- 타워는 한국 시간 자정마다 바뀌며, 서버와 모든 플레이어가 같은 타워를 받습니다.

### 일일 순위표

- 그날의 최고 기록이 서버에 저장되어 모두가 같은 순위표를 봅니다.
- 서버를 다시 시작해도 기록은 남습니다.

### 공정한 기록

- 서버가 플레이어의 이동과 체크포인트 도착을 검증합니다. 비정상적으로 빠르거나 순서를 건너뛴 기록은 인정되지 않습니다.
- 완주 시간은 서버가 직접 잰 시간과 대조해 확인합니다.

## 접속 안내

- 계정은 없습니다. **닉네임**을 정하고 바로 참여합니다.
- 연결이 끊기면 혼자 하는 플레이로 계속 이어지고, 다시 연결되면 자동으로 방에 돌아옵니다.
- Robo Builder, Craft Island, Blast Royale은 서버 없이 브라우저 안에서 동작합니다. 진행 상황도 브라우저에 저장됩니다.

## 알려진 문제

- 타워를 오르는 도중 연결이 끊겼다가 다시 연결되면, 서버에 기록된 체크포인트 진행이 처음부터 다시 시작됩니다.
- 계정이 없기 때문에 같은 닉네임을 다른 사람이 쓸 수 있습니다.
