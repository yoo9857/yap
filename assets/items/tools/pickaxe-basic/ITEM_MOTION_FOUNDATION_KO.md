# 아이템 동작 기반 · 1.1.0

HOME·TT의 승인된 엄지 블록 손과 사선 곡괭이 그립을 유지하면서, 손과 물건이 한 덩어리로 움직이도록 장착 동작을 개선했습니다. 모델을 별도로 흔들거나 손 안에서 회전시키지 않습니다.

## 조절 위치

기준 설정은 assets/items/tools/pickaxe-basic/item.json입니다.

| 설정 | 역할 |
| --- | --- |
| grip.bindOffset / rotation / handleSlide | 엄지·손바닥 틈과 손잡이 축 |
| grip.liftRotation / equipSeconds | 장착할 때 팔을 조금 들어 쥐기 |
| grip.motion.sourceArmWeight / attackArmWeight | 맨손 이동 클립이 장비를 든 팔에 섞이는 비율 |
| grip.motion.walkSway / runSway / idleSway | 발걸음·속도·대기에 따른 작은 회전, 단위 rad |
| grip.motion.turnLag / accelerationLag | 몸 회전·출발·정지에 따른 짧은 관성 |
| swing.phases / pitch / side | 준비·내려찍기·타격 후 잔동작·복귀 궤적 |
| swing.seconds / impactAt / impactNode | 옵션별 스윙 주기와 타격 시점·날 기준점 |

새 도구는 같은 장착·동작 코드와 설정 구조를 바탕으로 조정할 수 있습니다. 이번 실제 자산/방향 검수 대상은 첫 곡괭이와 HOME·TT입니다. 다른 도구의 크기·무게·그립은 새 정의와 별도 모델 검수가 필요합니다.

## 실제 수정

- 각 캐릭터의 처음 Idle에서 자연스러운 팔의 롤을 보관합니다. 달리던 중 장착해도 달리기의 큰 팔 스윙을 기준 자세로 저장하지 않습니다.
- 이동 클립의 큰 팔 움직임을 줄이고, 실제 걸음 위상과 속도에 작은 흔들림을 맞춥니다. 정지 후에는 감쇠하며, 방향의 ±180° 경계는 최단 각도로 계산합니다.
- 회전 점프나 위치 초기화가 큰 관성으로 남지 않도록 회전 속도를 제한합니다. 공격 중에는 보폭과 관성을 줄입니다.
- 손·도구는 같은 짧은 팔을 공유합니다. 이전 프레임의 보정은 믹서 전에 제거하며, 어깨 캡 연결을 마지막에 보정합니다.
- 공격 타격 시점은 프레임별 지연 필터 대신 설정의 스트로크 위상으로 평가합니다. 중단 시에는 마지막 회전에서 복귀합니다.
- 기본 장비/네 옵션 모두 기존 거리·정면 각도·단일 블록 채굴 규칙을 유지합니다. 타격 날의 표시 구체는 실제 광역 충돌 판정이 아닙니다.

## 검수

- 전체 클라이언트: 50개 파일, 438개 테스트 통과. 아이템 관련 17개, 기존 어깨/전환 연결 10개 통과.
- HOME·TT × 네 방향 × 네 옵션, 총 32개 이동 중 공격 조합을 확인합니다.
- 보폭 흔들림 범위·접점 유지·정지 감쇠·회전 경계·준비/타격/복귀 중단·30/60/144fps 타격 자세를 검사합니다.
- 몸통 내부 기준 박스에 대한 도구 표본 관통 0건. 이 검사는 보수적인 내부 기준영역 검사이며 모든 표면 간 충돌의 증명은 아닙니다.
- 정면·왼쪽·오른쪽의 실제 런타임 자세 렌더 24장과 5초/20fps 동작 렌더를 생성했습니다. 실시간 게임 화면 녹화가 아닙니다.
- 타입 검사·변경 파일 린트·프로덕션 빌드 및 별도 동작 검수 화면 번들 검사 통과.

실제 게임 검수는 /?mode=craft&pickaxe=1이며 H 장착/해제, Shift+H 옵션입니다. 개발 서버의 item-preview.html에는 대기·걷기·달리기·회전·정지 공격·이동 공격과 네 방향 카메라, 일시정지·단발 공격·속도 조절을 제공합니다. 일반 게임 기본 활성화와 원격 장비 동기화는 이번 범위에 포함하지 않았습니다. 라이브 브라우저 동작 검수는 완료하지 않았습니다.
