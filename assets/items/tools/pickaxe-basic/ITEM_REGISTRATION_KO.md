# 포근한 곡괭이 · 실제 아이템 등록 1.2.0

곡괭이를 인벤토리 아이템으로 등록했습니다. 게임에서 보유하고 선택한 핫바 칸이 장착과 공격 모드의 기준입니다. 검수용 URL 플래그나 임시 장착 토글은 사용하지 않습니다.

## 사용 방법

1. 일반 게임 /?mode=craft를 엽니다. 기존 게임은 새로고침합니다.
2. E → 가방의 도구 분류에서 포근한 곡괭이를 찾습니다. 새 게임과 기존 저장 모두 기본 도구 1개가 지급됩니다.
3. 원하는 핫바 칸에 넣고 그 칸을 1–9 또는 휠로 선택합니다.
4. HUD에 공격 모드가 표시되고 실제 손에 도구가 장착됩니다. 왼쪽 클릭은 한 번의 전방 내려찍기, 길게 누르면 연속 공격·채굴입니다.
5. R로 옵션을 바꿉니다. H는 기존 조작법 메뉴로 유지합니다. 블록·물통·빈손으로 바꾸면 곡괭이 장착과 공격이 중지됩니다.

## 연결한 기능

- itemCatalog.ts: 블록·유체·도구의 가방/핫바 표시. 도구에 지형 셀 ID를 할당하지 않습니다.
- inventory.ts: 도구 보유 수량, 최대 수량 1개, 저장/핫바 복원·이동 지원. 기존 블록·물통 칸은 유지됩니다.
- itemAttack.ts: 한 번의 클릭을 전체 스트로크로 실행하고, 홀드는 반복하며 해제 시 현재 주기를 마칩니다. 장비 변경·자세 변경·메뉴 진입은 공격을 취소합니다.
- craftGame.ts: 실제 소유·선택 상태로 장착/공격/블록 판정을 연결합니다. 허공에서도 동작하며, 타격 58% 지점에서 유효한 블록에만 작업량을 적용합니다.
- bag.ts / craftHud.ts: 도구 분류, 원본 아이콘, 사거리·주기·사용 안내와 공격 모드 표시. 곡괭이 장착 중 지형 배치 미리보기와 블록 설치를 숨깁니다.
- 교실: 선택 장비 ID·옵션·공격 위상을 검증해 서버가 중계하며 다른 플레이어의 리그에 적용합니다. 사람 피해/친구 밀기를 곡괭이 공격으로 적용하지 않고, 교사의 건축 잠금도 유지합니다.

## 저장과 배포

일반 섬의 기존 저장 데이터와 들판 저장 구조는 아이템 키와 핫바를 그대로 보관합니다. 기본 도구를 기존 플레이어에게도 제공하며, 저장된 핫바를 임의로 덮어쓰지 않습니다. 교실 장비 표시는 클라이언트와 서버에 이 변경을 함께 배포해야 합니다. 이번 작업에서는 로컬 파일과 빌드만 반영했습니다.
