# 곡괭이 디테일 점검 · 1.2.3

승인한 1.2.2의 몸 가까운 그립과 공격 곡선을 유지하고, 실제 사용 전환에서 찾은 네 가지 누락을 수정했습니다.

- 장착 해제: 도구/공격은 즉시 해제하고 팔·상체 보정은 0.18초에 걸쳐 복귀합니다. 빠르게 재선택하면 같은 인스턴스/소켓에서 이어집니다. 복귀 후 인스턴스 재질은 해제하며 공유 모델 지오메트리는 보존합니다.
- 클릭 입력: 현재 공격 도중 다시 누른 클릭을 다음 공격 한 번으로 보관합니다. 클릭을 여러 번 해도 계속 쌓이지 않고, 장비/자세 변경 시 취소됩니다. 길게 누르다가 해제할 때 불필요한 추가 주기가 붙지 않습니다.
- 투명 장착: 도구가 투명한 상태에서 깊이 가림, 그림자, 잉크 마스크가 먼저 보이지 않도록 처리했습니다. 외부 투명도 조정에도 같은 규칙을 적용합니다.
- 물 클릭: 곡괭이·블록·빈손에서는 물을 제거하지 않으며, 실제 선택한 물통에서만 기존 scoop 동작을 실행합니다.

HOME/TT의 대기·타격 중 해제 검사에서 첫 복귀 프레임의 손 이동은 이전 약 12~17cm에서 약 0.03~0.99cm로 줄었습니다. 이는 같은 초기화/시간으로 측정한 120fps 첫 프레임 값입니다. 빠른 두 클릭은 두 타격으로 처리됩니다.

전체 클라이언트 52개 파일·467개 테스트 통과. 관련 66개, 새 회귀 6개를 포함합니다. 타입·변경 파일 린트·프로덕션 번들 빌드 통과. 기존 dist 파일 정리에서 권한 오류가 발생해, 작업 폴더의 새 출력 경로로 빌드를 완료했습니다. HOME·TT × 네 방향 × 네 옵션 × 정지/달리기 64개 조합과 30/60/144fps 타격 검사가 포함됩니다.

장착 해제 중 리그 내부에는 짧은 복귀 보정만 남으며, 실제 장비 ID는 즉시 null로 바뀝니다. 파괴 판정/사거리/옵션 효율/모델/텍스처/Blender 원본은 변경하지 않았습니다. 실시간 브라우저 조작과 배포는 완료하지 않았습니다.
