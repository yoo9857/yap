# Garage UI image assets v1

Generated with the built-in ChatGPT `image_gen` tool. The PNG masters are preserved in `raw/`; the runtime WebP files are in `apps/client/public/ui/garage/v1/`. `build.py` only trims unused alpha padding and encodes runtime files; it does not redraw the generated art.

## Art direction

Use our existing cream, mint and honey building-block materials with a restrained navy control surface. Keep the approved horizontal workbench and large live preview. No card-based menus or vertical side panels. All lettering, icons, hit areas and accessibility states stay in the application.

Style references: the real `frame.webp` block render and the approved `parts-1600.png` game screenshot. Pinterest searches were attempted, but the pages were inaccessible. Public block-game UI research included [LEGO 2K Drive UI art](https://www.behance.net/gallery/206729117/LEGO-2K-DRIVE-UI-ART) and [LEGO Horizon Adventures UI identity](https://chrisfrancis46.artstation.com/projects/0lDPly); no third-party artwork is shipped.
