기존에 정상인 항목도 확인했다. 한글·영문 브랜드와 블록 게임 설명, 일반 사용자와
수집기에 동일한 정적 본문, HTML 게임 안내·FAQ와 구조화 데이터의 일치, 사이트맵,
robots, 실제 404, HTTP/www 대표 도메인 통합, 384×384 정사각형 PNG 파비콘이다.
공개 DNS의 A 레코드는 운영 서버를 가리킨다. AAAA 레코드가 없다는 사실 자체는
IPv4로 제공되는 이 사이트의 검색 누락 원인으로 판단하지 않았다.

Google DNS 소유권 TXT나 HTML 인증 메타 태그를 공개 소스에서 확인하지 못했지만,
이것만으로 검색 콘솔 미등록이라고 단정할 수는 없다. 과거 인증 파일이나 계정의
실제 소유권 상태는 계정에서 확인해야 한다.

남은 운영 작업:

1. Google Search Console에서 `/`, `/guide/` URL 검사 및 색인 요청, 사이트맵 제출 확인.
2. 네이버 서치어드바이저에서 소유권·수집·색인 상태 확인. IndexNow 알림 접수와
   계정 보고서 연결·검색 노출은 별개다.
3. 1~2주 뒤 `크래프트얍`, `CraftYap`, `크래프트얍 블록 게임`의 노출/클릭과
   실제 색인 URL 확인. 오래된 부업 제목이 남으면 재수집 결과와 대표 URL을 확인.
4. 이용자용 문의·운영자 정보는 아직 공개 페이지에서 확인되지 않는다. 사용할 공식
   연락처가 정해지면 게임 안내에 추가한다. 이름이나 주소를 임의로 만들지 않는다.

GEO는 검색 가능한 원문, 실제 기능과 일치하는 설명, 읽을 수 있는 표·질문과 답변을
중심으로 운영한다. llms.txt나 FAQ 스키마를 추가했다는 이유만으로 AI 인용·검색 순위가
보장되는 것은 아니다.
