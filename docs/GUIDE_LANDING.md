# 게임 랜딩 페이지

`/guide/`는 게임을 보여 주고 실제 플레이로 연결하는 한글 랜딩 페이지다.
기존 공식 게임 설명·조작법·저장 안내·FAQ와 구조화 데이터는 유지한다.

## 구성

- 실제 게임 화면을 사용하는 메인 비주얼. 탐험/기계/타워 화면 전환과 확대 보기.
- Craft Island, Daily Tower, Robo Builder, Blast Royale의 실제 화면과 모드 바로가기.
- 기계 작업실, 공동 교실, 시작 방법과 PC 조작법.
- 조작법은 카드 그리드다. W A S D는 실제 키보드 배열로, 마우스는 해당 버튼을 칠한 그림(인라인 SVG)으로 보여 준다.
  게임의 `ui/inputGlyphs.ts`와 같은 모양이므로 한쪽을 바꾸면 다른 쪽도 맞춘다.
- FAQ는 네이티브 `details`를 쓴다. JavaScript를 끄면 그대로 읽고 펼칠 수 있다.
- 모바일 메뉴와 하단 플레이 버튼. 반복 자동 재생이나 불필요한 3D 실행은 없다.

`guide.js`는 메뉴·사진 전환·이미지 확대만 담당한다. 게임 번들은 이 페이지에서
불러오지 않는다. JS가 없을 때 이미지 링크는 원본을 열고, 모든 게임 링크가 작동한다.
`?mode=education`은 교육 모드의 선생님/학생/혼자 선택 화면으로 바로 연결한다.
`?mode=field`는 기존처럼 혼자 하는 들판을 바로 시작한다.

## 실제 게임 이미지

`apps/client/public/guide/assets/`의 다섯 WebP는 2026-10-28에 로컬 게임을 직접
실행해 1440×900 해상도로 촬영했다. 게임 HUD만 감춘 장면이며 생성형 이미지나
다른 게임의 화면이 아니다. 실제로 제공하는 기능만 소개한다.

| 파일 | 촬영 장면 |
|---|---|
| island.webp | Craft Island의 블록 마을, 로봇과 반려동물 |
| workshop.webp | 기계 작업실에서 조립한 비행체의 시험 비행 |
| tower.webp | Daily Tower의 실제 블록 발판 |
| builder.webp | Robo Builder의 피라미드 건설 장면 |
| battle.webp | Blast Royale의 실제 섬과 블래스터 |

이미지 합계는 약 824KB다. 첫 화면 이미지만 우선 로드하고 아래 이미지는 지연 로드한다.
CSS·JS는 공개 정적 파일이므로 교체할 때 HTML의 `?v=`도 갱신해 캐시 혼용을 막는다.
FAQ 본문을 바꾸면 HTML에 들어 있는 FAQ 스키마도 동일하게 바꾼다.
