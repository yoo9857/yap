# 메인광장 — 웹 클라이언트

게임 모드의 가장 큰 입구는 **메인광장 접속**이다. 제작한 일곱 나라 월드가 열리며, 플레이어가 중앙 광장에서 만나서 이동하고 방을 만들거나 참여한다. 개별 게임 카드와 기존 방 서비스는 유지한다.

## 실행

프로젝트 루트에서 pnpm dev를 실행한다. 게임 모드 → 메인광장 접속, 또는 http://127.0.0.1:5173/?mode=plaza 로 입장한다. Vite는 IPv4 루프백에 바인딩하며 API·WebSocket 프록시는 127.0.0.1:8081을 사용한다. 이 개발 주소는 같은 컴퓨터에서만 열린다. 배포 환경의 초대 링크는 해당 서비스의 주소를 쓴다.

## 플레이 흐름

- 처음 접속하면 이름을 정한다. 같은 채널에서 실제 접속한 캐릭터·이름·움직임과 채팅을 공유한다.
- 채널당 32명. 일반 접속은 빈 채널에 배치하고, 친구 초대 링크는 현재 채널 번호를 포함한다. 지정한 채널이 가득 차면 다른 채널로 조용히 옮기지 않고 이유를 보여 준다.
- 광장의 방 만들기 / 열린 방 / 코드 참여는 기존 PartyLobby와 PartyManager를 사용한다.
- 현재 함께 시작할 수 있는 게임은 함께 짓기와 Daily Tower다. Robo Builder와 Blast Royale의 멀티플레이를 새로 구현한 것은 아니다.
- 광장에서 시작한 파티 게임의 처음으로 버튼은 같은 광장 채널과 기존 파티 자리로 돌아온다.
- PC: WASD·방향키 이동, 화면 드래그 시점, 휠 확대, Space 점프. 터치: 왼쪽 조이스틱, 화면 드래그, 점프 버튼. 메뉴와 입력 중에는 이동을 멈춘다.

## 모델·충돌

apps/client/public/world/main-plaza/의 GLB와 충돌 JSON은 미터·Y-up 좌표다. 원점·건물·소품을 다시 스케일하지 않는다. 몸체는 폭 0.6m, 높이 1.8m 캡슐이며, 계단 자동 오르기 높이는 0.32m다. 바위는 삼각형 충돌체를 쓰며 같은 바위의 대체 외곽 박스를 중복 적용하지 않는다.

모델·충돌을 갱신하면 src/plaza/worldManifest.json의 version도 두 파일의 내용에 따라 변경한다. 메인광장 코드는 해당 모드 선택 후에만 내려받는다. 웹과 터치 웹을 위한 구현이며, 별도의 Rust Android 네이티브 클라이언트에는 아직 이 광장을 연결하지 않았다.

## 분위기 — 크래프트 모드와의 연동 (`src/plaza/plazaAtmosphere.ts`)

모델 위에 크래프트 모드가 이미 가진 것을 얹는다. 전부 **재질 이름**으로 찾으므로(내보내기가 재질별로 메시를 합친다) 모델을 다시 내보내도 숫자를 고칠 필요가 없다.

- **하늘**: 크래프트 하늘의 규칙(지평선 = 안개 색, 그래서 먼 땅이 하늘로 녹아든다)을 따르는 광장 전용 돔. 해와 천천히 흐르는 구름을 셰이더로 그린다. 노이즈의 해시는 **정수 해시**여야 한다(실수 해시는 같은 격자점이 이웃 칸마다 미세하게 다른 값이 되어 구름이 조각난다). 모델의 구름 메시는 안개를 받지 않게 한다(안개색 파편으로 보였다). 하늘 반사 맵은 크래프트의 `createSkyEnvironment`. 반사는 유리·금속·얼음처럼 이름으로 고른 재질에만 준다. 광택 수치로 고르면 클리어코트가 있는 벽까지 하늘이 비쳐 마을 색이 바랜다.
- **물**: 이름에 `water`가 있는 재질의 메시는 크래프트의 물 셰이더(`makeWaterMaterial`)로 그리고, 마우스가 있는 기기에서는 물 파이프라인(`render/waterPipeline.ts`)을 쓴다. 메시를 월드 좌표로 옮겨 크래프트 물의 속성(`aWave` 등)을 붙이며, **위를 향한 면만** 물로 쓴다(모델의 물은 옆면·밑면이 있는 판이라, 다 그리면 타일마다 작은 수조가 되어 바다에 격자 줄이 생긴다).
- **바다**: 항구 나라의 땅(`country-harbor`)은 바다다. 그 판을 1.4 m 내려 바닥으로 두고 원래 높이에 크래프트 물을 올린다. 충돌은 그대로라 캐릭터는 수면 위를 걷는다.
- **세계를 둘러싼 바다**: 반지름 640 m의 크래프트 물 원판(y −0.5)과 그 아래 바닥. 땅 밑에 깔려 있어 땅이 끝나는 곳에서만 보인다. 광장이 안개 속 판이 아니라 섬이 된다.
- **발밑 먼지**: 달리는 걸음과 착지에 나라의 땅 색 먼지가 인다(`puff`, 점 64개짜리 고리 버퍼, 던질 때만 쓴다).
- **땅**: 나라의 땅·잔디·모래·눈 재질은 픽셀 셰이더에서 월드 좌표로 0.5 m 간격 스터드와 크레용 질감을 그린다. 삼각형과 텍스처는 늘지 않고, 멀리서는 스터드가 한 픽셀보다 작아지기 전에 사라진다.
- **나라별 공기**: 카메라를 따라다니는 점 구름 하나(그리기 1번). 서 있는 나라에 따라 색·크기·움직임과 안개·하늘 색, 하늘빛(반구 조명)이 몇 초에 걸쳐 바뀐다. 두 픽셀보다 작은 점은 그리지 않는다(낮 하늘의 별처럼 보였다)(성: 꽃잎, 정글: 반딧불, 눈: 눈송이, 사막: 모래, 톱니: 불티 등). 표는 `AIR`.
- **빛**: 발광 재질은 천천히 숨 쉬듯 밝기가 변하고, 등마다 부드러운 빛 번짐 점을 하나씩 둔다.
- **바람**: 잎 재질은 정점 셰이더에서 월드 좌표 기준으로 흔들린다. 구름과 풍선은 천천히 떠다닌다.
- **소리**: 배경 음악, 그리고 캐릭터의 걸음에 맞춘 발소리(나라마다 바닥 소리가 다르다: `GROUND`), 점프와 착지.

터치 기기는 점이 적고 물 파이프라인을 쓰지 않는다(크래프트와 같은 기준). 화면 확인은 `node C:/craftyap-fxbake/shot-plaza3.mjs <outdir> [tag]` — 개발 훅 `__roboPlaza.offline()`(서버가 순간 이동을 되돌리므로 먼저 끊는다), `teleport`, `view(from, to)`, `atmosphere()`로 중앙과 일곱 나라를 실제 GPU로 찍고 프레임 수를 적는다.

## 검사

클라이언트의 test/plaza-physics.test.ts는 실제 내보낸 충돌 데이터를 사용하여 바닥 보행과 40단 성 진입 계단을 검사한다. 서버의 test/plaza.test.ts와 test/party.test.ts는 접속·늦은 입장·이동 전달·순서·채널 분리·정원·잘못된 이동 보정·기존 방 규칙을 검사한다. 실제 브라우저 화면과 네이티브 Android 성능 검증을 대신하지 않는다.
