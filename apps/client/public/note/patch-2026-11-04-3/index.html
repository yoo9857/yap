11월 4일 패치 노트 (3) — 조준 테두리를 차분하게, 깜빡임 없이

오늘 바꾼 조준 테두리의 검은색과 흰색이 너무 세게 부딪혀 보이고, 화면을 돌릴 때 흰 선이 깜빡이던 문제를 고쳤어요. 이제 흰 선에 옅은 그림자만 깔아 어떤 블록 위에서도 차분하고 또렷해요.

  • 패치 노트
  • 버그 수정
  • 블록
  • 화면
수정 1개선 1알려진 문제 1

요약한눈에 보기

(2)에서 바꾼 조준 테두리는 검은 선 위에 흰 선이라 블록 위에서 너무 튀었고, 화면을 돌릴 때마다 흰 선이 깜빡였어요. 이제 흰 선 + 옅은 그림자 한 가지로 바꿔서 어두운 돌, 흰 양털, 빨간 벽돌 어디서나 차분하게 잘 보이고, 깜빡이지 않아요.

BEFORE / AFTER

같은 자리에서 같은 블록을 바라볼 때 — 위는 (2)의 검정+흰색 테두리, 아래는 새 테두리예요.

FIX버그 수정 1

  • 화면을 움직이면 흰 선이 깜빡이던 문제검은 선과 흰 선이 정확히 같은 깊이에 그려져서, 화면이 조금만 움직여도 어느 쪽이 앞에 보일지가 매번 바뀌었어요. 화면을 돌리며 측정해 보니 흰 선이 거의 보이지 않는 화면도 있었어요. 이제 두 선이 서로 겨루지 않게 그려서 매 화면 같은 모습이에요. 멀리 있는 블록에서 선이 블록 면과 겨루던 것도 함께 고쳤어요.

UP개선 1

  • 조준 테두리 색검은색과 흰색이 세게 부딪혀 보이던 것을, 흰 선 아래 옅은 그림자만 까는 방식으로 바꿨어요. 흰 블록 위에서는 그림자가, 어두운 블록 위에서는 흰 선이 테두리를 보여 줘요. 기계 작업실 조립 커서도 같아요.

!알려진 문제 1

  • 이미 열려 있던 탭은 새로고침해야 바뀐 화면이 보여요.
