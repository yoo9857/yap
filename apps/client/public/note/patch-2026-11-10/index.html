11월 10일 패치 노트 — F2에서 반 전체 물 한 번에 빼기

선생님 수업 도구에 빠르게 물 빼기를 추가했어요. 학생들이 설치한 물과 퍼진 물을 반 전체에서 한 번에 정리하고, 건물과 가구는 그대로 남겨요.

  • 패치 노트
  • 새 기능
  • 교실
  • 수업 도구
  • 물
신규 3개선 3

요약한눈에 보기

학생들이 물을 많이 설치해 들판이 잠겼을 때, 선생님이 F2 → 💧 빠르게 물 빼기를 누르면 반 전체의 물을 한 번에 없앨 수 있어요. 학생들이 만든 건물과 가구는 그대로 남고, 정리된 모습은 선생님과 학생 화면에 함께 반영돼요.

BEFORE / AFTER

NEW새로 추가 3

  • F2 → 빠르게 물 빼기수업 도구 아래쪽의 파란 버튼을 누르면 바로 실행돼요. 휴대폰·태블릿에서는 선생님의 수업 도구 버튼으로 같은 메뉴를 열 수 있어요.
  • 반 전체의 물을 정리해요어느 학생이 설치했든 물의 근원, 퍼지는 물, 고인 물, 모양 블록 안에 들어간 물까지 제거해요. 지금 화면 밖에 있는 물도 함께 정리돼요.
  • 선생님만 실행할 수 있어요학생 화면에는 이 버튼이 없어요.

UP개선 3

  • 만든 것은 유지해요건물·가구와 수업 설정을 유지하면서 물만 제거해요. 들판을 통째로 비우지 않아도 돼요.
  • 반 모두 같은 화면으로물이 많아도 정리 명령을 한 번에 전달해요. 학생들이 수업에서 나가거나 새로 들어올 필요가 없어요.
  • 다시 들어와도 정리된 들판물을 뺀 결과도 반에 저장돼요. 멀리 갔다 돌아오거나 새로고침해도 제거한 물이 다시 나타나지 않아요.

알아 두기

  • 이 버튼은 반 전체를 정리해요. 특정 학생의 물만 골라 제거하는 기능은 아니에요.
  • 정리 후에도 학생들은 새로 물을 설치할 수 있어요. 물을 정리하는 동안 건축을 잠시 멈추려면 F2의 건축 잠금을 함께 사용할 수 있어요.
  • 업데이트 후 열려 있던 교실 화면은 같은 반으로 자동 재접속해요. 버튼이 보이지 않으면 한 번 새로고침해 주세요.
